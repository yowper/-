# 手机助手（volumeswipe）

**一个用语音控制视频 App 的 Android 无障碍小工具。** 说一句话，它帮你暂停/播放、翻下一集、跳过广告、调音量、调亮度、打开 App。

不用 root，不用连电脑，**只需要打开无障碍服务**。

| | |
|---|---|
| 应用名 | 手机助手 |
| 包名 | `com.example.volumeswipe` |
| 版本 | 2.4（versionCode 24） |
| 系统 | Android 7.0+（minSdk 24），targetSdk 34 |
| 架构 | **只含 arm64-v8a**（近几年的手机都是，老 32 位机装不上） |
| 体积 | 约 56 MB（里面打包了 65 MB 的中文语音识别模型 + 11 MB OCR 引擎） |
| 下载 | https://github.com/yowper/volumeswipe/releases （每个版本一个 APK） |

## 一、装好后按 ①②③④ 走一遍

打开 App，主界面上从上到下就是这四步：

| 步骤 | 按钮 | 作用 |
|---|---|---|
| ① | 允许后台运行（忽略电池优化） | 不点它，MIUI / 鸿蒙 / ColorOS 过一会儿就把服务杀掉 |
| ② | 授予悬浮窗权限 | 屏幕上要显示那条小命令条 |
| ③ | 打开无障碍设置并开启本服务 | **核心**，没这个什么都干不了 |
| ④ | 开启后台常驻服务 | 通知栏出现「手机助手 · 运行中」，进程优先级提到最低 |

另外两个可选：

- **☀ 允许修改系统设置** —— 只有说「亮 / 暗」调屏幕亮度才需要，点它跳到系统页把开关打开。
- **▶ 测试Mic（标定麦克风位置）** —— 如果唤醒后豆包键盘出来了却没开始听，点这个：程序弹出键盘后，你**手点一下键盘上的麦克风按钮**，它就把你点的位置记下来（默认 22%, 66%），以后自动点。

再去系统设置里放行三项（每个 ROM 名字不同，意思一样）：**自启动**、**后台弹出界面 / 后台运行**、**电池无限制**。

## 二、两套识别路线

由主界面那个勾 **「使用豆包语音输入法」**（默认勾选）决定：

### 勾选豆包（推荐）

```
听到「嗨小白」
  → 【什么都不做】：不静音、不在视频上点任何地方
  → 屏幕上弹出输入框 + 立刻弹键盘
  → 自动点一次豆包输入法的麦克风（默认 22%, 66%）
  → 你对着豆包说命令
  → 框里一出现短句（≤6 个中文字）就立刻收尾执行
  → 最长等你设置的秒数（默认 3 秒）
```

也就是**不靠本地语音听命令，命令全交给豆包输入法**——它听得比本地模型准得多。

- 说「打开豆包」＝把设置里这个勾**勾上**（并且立刻叫出豆包键盘让你直接说话）
- 说「关闭豆包」＝把勾**去掉**
- 说「豆包」＝**切换**（勾着就关、没勾就开）
- 说「打开豆包应用」＝启动豆包这个 App（跟上面三个意思不同）

### 不勾选豆包（纯本地）

不用唤醒词，本地语音引擎（Vosk 中文模型，已打进 APK）听整个命令表，听到命令直接执行。

### ⚠️ 两种情况都一样：**不用唤醒词也能下命令**

没听到「嗨小白」时，本地引擎会先自己认一遍——**只要能对上任何命令就直接执行**（只收 8 个字以内的短句，长句当视频里的话不理）。
所以下面这些你**可以直接说，不必先说「嗨小白」**：

```
停    放    下一集    上一集    上页    下页    广告    直播
大    小    亮    暗    抖音    红果    打开豆包    关闭豆包    小白再见
```

## 三、完整命令表

| 你说 | 它做什么 |
|---|---|
| `嗨小白` / `小白` | 唤醒：只弹键盘 + 点一次豆包 Mic，**不动屏幕、不静音**（不和命令组合，后面说的一律不算） |
| `停` `放` `继续` `播放` `继续播放` `暂停` `恢复播放` `接着看` `开始播放` | 同一条命令：**在 (50%,20%) 点一下**（点击时长默认 120ms） |
| `下一集` `下一部` `换一集` `上翻` `下集` `下一级`… | 上滑：(50%,75%) → (50%,25%)，时长默认 300ms |
| `上一集` `上一部` `下翻` `上集` `上一级`… | 下滑：反方向 |
| `广告` `退出广告` `跳过广告` `关掉广告` `跳过这段广告` | **先看下方读秒，读秒走完自动上拉**（不左划） |
| `直播` `退出直播` `推出直播` | 比「退出广告」多一个动作：**先从屏幕最右边缘往左划**，再读秒上拉 |
| `上页` / `下页` | 点 (15%, 85%) / 点 (85%, 85%) |
| `大` `大一点` `声音大` `音量大` `大点声` `调大` | 媒体音量 +1 格 |
| `小` `小一点` `声音小` `音量小` `小点声` `调小` | 媒体音量 −1 格 |
| `亮` `亮一点` `调亮` `变亮` | 屏幕亮度 **+25**（0~255），需要 ☀ 授权 |
| `暗` `暗一点` `调暗` `变暗` | 屏幕亮度 **−25**，需要 ☀ 授权 |
| `抖音` `红果` `番茄` `证券`（`股票`/`炒股`）`ds`（`deepseek`）`天鹅` `阅读` `b站` `快手` `微信`，或 `打开抖音`… | 直接启动对应 App（喊名字就行，不必说「打开」） |
| `豆包` / `打开豆包` / `关闭豆包` | 切换 / 勾上 / 去掉「使用豆包语音输入法」 |
| `打开豆包应用` | 启动豆包 App |
| `测试读秒` | 弹出读秒探测面板，看当前屏幕下方能不能读到读秒 |
| `小白再见` `再见小白` `小白拜拜` | 彻底退出（清配置、停常驻服务、收窗口） |

### 防止识别抖动（自动，不用管）

- 同一条命令 **1.5 秒内只执行一次**
- **唤醒词不和命令组合**：句子里只要出现唤醒词，就只当唤醒，后面说的一律不解析。
  所以「嗨小白下一集」「小白广告」这种**不会执行任何命令**（命令要分开单独说）。
  说「嗨小白」只会唤醒，也不会被当成命令（曾经它会命中单字“小”→ 把音量一路压到静音）
- 唯一例外：「小白再见 / 再见小白 / 小白拜拜」照旧彻底退出
- 成对命令（大/小、上/下、亮/暗…）**3 秒内不许反着再来一次**（否则本地引擎会把「声音大一点」听成「声音小」）
- **一个字的命令（`停` `放` `大` `小` `亮` `暗`）只在真的有视频/声音在播时才执行**：
  视频停了、或者页面上根本没在放的时候听到一个单字，只会写一条日志、不动屏幕（日志：`听到了「停」，但没执行：现在没有视频/声音在播`）
- 每条被拦下的都会写进日志，写明拦的原因

## 四、「退出广告 / 退出直播」的读秒是怎么做的

视频 App 的界面文字**读不到**（无障碍窗口列表里只有输入法和我们自己的悬浮条），所以用**截屏 + OCR**：

1. 截屏（Android 11+ 的无障碍截屏，1 秒最多一次，**不需要**「录屏授权」这个弹窗）
2. OCR 只读**屏幕最下方 20%**，找 `N 秒`（那句「🔒 10 秒后可继续看下一集」）
3. **读到 N 秒 → 等 N−1 秒再上滑**。
   为什么减 1 秒：截图 + 识别本身要花掉大半秒，读到的秒数已经过时了；而**宁可晚一秒也不能早**——广告读秒期间是**锁着**的，早滑等于白滑。
4. 连续两次都读不到读秒 → 判定下方没有读秒文字，**直接上滑**
5. 上滑后 3 秒比对页面：**没变就补滑，最多 4 次**（每次隔 1.5 秒）——因为读秒没走完时那一次上滑是白滑的

日志会写清每一步：`读到读秒 10 秒 → 等 9 秒后上滑` / `上滑第 1 次` / `完成（共上滑 2 次）`。

## 五、参数设置（⚙ 参数设置）

| 参数 | 默认 | 说明 |
|---|---|---|
| 上滑时长 | 300 ms | 越小越"甩"，越大越"拖" |
| 命令冷却 | 2000 ms | 同一句话两次触发的最小间隔 |
| Mic X / Y | 22 / 66（%） | 豆包键盘上麦克风按钮的位置，用 ▶ 测试Mic 自动标定 |
| 点开 Mic 后最多等豆包多久 | 3 秒 | 框里一出现 ≤6 字的短句会立刻收尾，不会真等满 |
| 点 Mic 前延时 | 200 ms | 键盘弹出后再等这么久才点 Mic |

点击位置**不在这里设**，都固定在代码里，想改说一声：
`暂停/播放 (50%,20%)`、`上页 (15%,85%)`、`下页 (85%,85%)`、`上滑 (50%,75%→25%)`。

### 摇一摇（主界面勾选，默认开）

摇一下手机 ＝ **点 (50%,20%) 暂停 → 600ms 后上滑**（等于"暂停并跳过这一段"）。
为保证不误触，需要 700ms 内连续 3 个加速度峰值才算一次真摇；手拿放手机、通知振动都不会触发。正在识别命令（框/键盘在身上）时也不响应。

## 六、日志在哪看（排错必备）

1. **通知栏**：常驻通知「手机助手 · 运行中」——不展开能看到**最近 3 条**，展开是**最近 5 条**（带 `HH:mm:ss` 时间）
2. **主界面**：中间那个 **📋 查看最近日志（排错用）** 按钮，弹出可滚动的完整日志

出问题把这两处的文字发出来就能定位。

## 七、后台能不能一直跑

**无障碍服务是系统托管的，不是 Activity 的附属**。把 App 从最近任务里划掉，服务通常照样活着。

真正会停掉它的只有三种情况：

| 情况 | 结果 | 处理 |
|---|---|---|
| 被 ROM 省电策略回收 | 服务静默丢失 | 开 ①（电池优化白名单）+ ④（常驻服务） |
| 手动「强行停止」 | 无障碍开关会被系统强制关闭 | 用 App 内的 ⑤ 退出，别用系统那一项 |
| 重启手机 | 无障碍服务由系统自动恢复 | 不用管（`onServiceConnected` 里会自动把常驻服务拉起来） |

本工程做的加固：前台常驻服务（带低优先级通知）、电池优化白名单入口、开机自动恢复、主界面三行状态自检（无障碍 / 常驻服务 / 电池优化，哪项掉了直接点对应按钮）。

### 怎么退出

点 ⑤ 退出会弹确认框：

| 选项 | 做了什么 | 下次怎么恢复 |
|---|---|---|
| **退出** | 写 `enabled=false`、停常驻服务（通知消失）、收窗口。无障碍开关保留 | 重新打开 App 自动恢复 |
| **彻底停用** | 在上面基础上再 `disableSelf()`，把系统里的无障碍开关一起关掉 | 到系统设置里重新开启 |

为什么不全用一个？`disableSelf()` 是单向的——Android 不允许程序自己把无障碍开关**打开**，必须用户手动确认。

## 八、常见问题

- **说「嗨小白」后键盘出来了，但豆包没开始听**：Mic 坐标没对上。点 **▶ 测试Mic**，程序弹出键盘后你手点一下麦克风按钮，它会记住位置。
- **说「亮 / 暗」没反应**：需要主界面 **☀ 允许修改系统设置** 授权（状态栏会写「未允许 ✗ 请点 ☀」）。部分 ROM 开着自动亮度会覆盖，程序会顺手把自动亮度关掉。
- **某条命令老是自己乱触发**：`停/放/大/小/亮/暗` 是单字命令，只有**视频/声音在播**时才会执行（没在播就只记日志、不动屏幕）；`广告/直播` 是两个字的，仍然可能被视频里的话命中。告诉我哪条乱触发，我把它限制得更严。
- **「退出广告」滑了但页面没变**：日志会写 `第 1 次看起来没生效 → 1.5 秒后再滑`，正常会自动补滑。如果 4 次都没成，说明读秒还没走完（把日志发我）。
- **通知栏没有「运行中」那条**：点 ④。Android 13+ 首次要允许通知权限。
- **生僻名字（红果 / ds / 天鹅）本地识别听不准**：本地模型缺少 `graph/words.txt`，无法做动态语法，现在是自由识别状态。这种情况用豆包模式（勾选那个勾）最准——直接说给它听。
- **装不上 / 闪退**：APK 只含 arm64-v8a，32 位老机器装不上。

## 九、自己编译

### 云端（推荐，本地不用装任何东西）

本工程自带 `.github/workflows/build.yml`：

- **push 到 main** → Actions 自动编译，约 3~4 分钟 → 在该次运行的底部 **Artifacts** 下载 `VolumeSwipe-debug.zip`
- **推 `v*` 标签** → 自动编译**并挂到 Release**，别人可以直接下载

```bash
git tag -f v2.5 && git push origin refs/tags/v2.5 --force
```

> workflow 里没用第三方 `setup-android` action（实测在 runner 上会失败），而是自己用官方 `commandlinetools-linux-11076708_latest.zip` + `sdkmanager` 装 `platforms;android-34` 和 `build-tools;34.0.0`。

### 本地一键（`build_apk.bat`）

双击即可，脚本会自己下载并解压 JDK 17 / Android cmdline-tools / Gradle 8.7（首次约 450 MB，用国内镜像），然后编译并把 `VolumeSwipe-debug.apk` 拷到桌面。

### Android Studio

`File → Open…` 选本工程目录 → 等 Gradle 同步 → 点绿色 ▶ 或 `Build → Build APK(s)`。

## 技术要点一览

| 需求 | 实现 |
|---|---|
| 模拟点击 / 上滑 / 下滑 / 边缘左划 | `AccessibilityService.dispatchGesture()`，失败自动补发一次 |
| 读屏幕下方读秒 | `takeScreenshot()`（Android 11+，无需录屏授权）+ ML Kit 中文 OCR，只读最下方 20% |
| 页面有没有变 | 截屏指纹比对（中间 20%~80% 灰度指纹），以及最下方 12% 的像素比对 |
| 本地语音 | Vosk `vosk-android:0.3.47` + 打进 assets 的中文小模型 |
| 豆包语音输入 | 弹出自己的输入框 → 抢焦点弹键盘 → 点豆包 Mic → 读框里的字 |
| 后台不死 | 前台常驻服务 + 电池优化白名单 + 无障碍服务系统托管 |
| 悬浮命令条 | `TYPE_ACCESSIBILITY_OVERLAY` 窗口，长按拖动记住位置，`FLAG_NOT_TOUCH_MODAL` 不挡下面的 App |
